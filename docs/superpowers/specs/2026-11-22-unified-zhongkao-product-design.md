# 统一中考复习产品设计

## 目标

把英语、语文和未来的化学任务放进同一个学习产品。首页同时展示各学科的今日任务和专项训练，学习会话根据任务类型选择不同交互。

## 产品结构

产品暂用工作名「中考复习」。名称保留可替换能力，不把英文学习作为品牌主语。

首页提供两组入口。

- 今日计划。系统按各学科的学习状态生成任务。
- 专项训练。用户选择学科、内容范围、训练方式和顺序。

英语支持两种目标等级。

- 认识即可。以读音、词义和选择判断为主，进入定期认识抽查。
- 需要默写。增加拼写输入和词组默写，结果进入正式复习进度。

英语词组支持全部词组、筛选结果、教材单元和手动选择。化学先注册任务类型和入口位置，等待方程式书写规则后接入具体编辑器。

## 交互模型

统一学习会话负责范围、顺序、进度、暂停、恢复和结果汇总。卡片渲染器按任务类型提供选择题、自由输入、答案揭示、自评和后续专业输入组件。

专项训练请求包含学科、范围、模式、顺序和是否写入正式进度。默认正式默写会更新学习状态，临时测试可以选择只记录本次结果。

## 数据边界

- 内容包包含学科、版本、内容实体和卡片定义。
- 学习状态按卡片保存，英语单词认识、拼写和例句使用独立卡片。
- 复习事件按用户、卡片、评分、时间和内容版本追加保存。
- PythonAnywhere 的英语档案在迁移完成前保留只读回退。
- Supabase 作为长期账号和复习事件后端。

## 迁移规则

PythonAnywhere 档案先备份，再通过旧词条到新卡片的映射导入当前学习状态。现有档案没有完整历史事件，历史时间线单独标记为不可重建。PIN 不能直接转换为 Supabase Auth 密码，迁移需要用户重新设置密码或完成一次性迁移。

## 路由和发布

应用内部使用 `/today`、`/practice`、`/library`、`/progress` 和 `/settings`。学科和专项范围进入会话请求。项目站点路径迁移到根站点或自定义域名时，旧 `/English-review` 地址保留跳转。
