# 默写首字符提示设计

## 意图

在新版 `/study` 的英文默写输入题中自动显示正确答案的第一个字符，帮助学习者启动回忆，同时保留完整默写要求。

## 设计

- 新词拼写和复习默写都显示提示。
- 提示取答案文本去掉前置空格后的第一个字符。`take care of` 只显示 `t`。
- 提示只作为界面文本，不写入输入框，也不改变现有判分、评分和进度保存逻辑。
- 已有斜杠形式答案继续使用当前 `headword` 的第一个字符作为提示。

## 方案取舍

- 直接显示提示符合“自动提示”的要求，改动集中在默写卡片。
- 点击后显示会增加操作步骤。
- 预填输入框会改变用户输入和判分边界。

## 验证

为首字符提取逻辑增加单元测试，并运行前端构建确认 TypeScript 和 Vite 构建通过。
