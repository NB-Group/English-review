SAPG

Structure-Aware Parallel Generation
结构感知并行文本生成

Abstract: We propose Structure-Aware Parallel Generation (SAPG): represent generation as a dependency graph over token blocks and decode by topological layers. This converts decoding from token time to graph-depth time, where the number of sequential synchronization rounds is governed by the graph critical path.

On a synthetic translation task, SAPG achieves up to 141.5× higher decoding throughput than greedy AR decoding on GPU.

摘要： 我们提出了结构感知并行生成 (SAPG)。通过将生成表示为依赖图并按拓扑层解码，我们将解码过程从线性时间转换为图深度时间。在合成翻译任务中，SAPG在保持精确性的同时，实现了比贪婪自回归解码高 141.5倍 的吞吐量。
